# BV2MP3 · PRODUCT

> 产品定位、目标用户与设计原则。最后更新：2026-10-27

## register

product

## 是什么

把 Bilibili 视频链接批量转成本地 MP3 的单机工具。用户在网页里粘贴链接（一行一个），后台下载音轨、用 ffmpeg 转码，结果落进本地文件夹。完全本地运行，无账号、无上传。

## 用户

- 主要用户：需要把 B 站收藏批量导出为音频的个人用户，用于通勤/离线收听。
- 典型动作：一次贴 5–40 个链接，按下开始，然后去做别的事，回来收结果。
- 不是：团队协作、云端 SaaS、公开发布站。

## 产品目的

把重复的下载与转码流程收进一个按钮，自己点一下即可完成。零 API 成本，断网也能用（除访问 B 站本身）。

## 语气

安静、可靠、不啰嗦。像一件用惯了的本地工具：进度清楚，失败明确到具体链接，不假装聪明，不庆祝。

## 反参考

- SaaS 控制台风：大数字、彩色卡片墙、渐变英雄区
- 霓虹科技风：深蓝近黑底 + 青紫渐变 + 发光边框
- 冒充 B 站官方视觉（不使用其品牌色与 logo）

## 战略原则

1. **一屏完成**：粘贴 → 开始 → 看进度 → 收文件，不开二级页面。
2. **状态诚实**：失败要指出是哪一条、为什么；不做「看起来成功」的假进度。
3. **本地优先**：不登录、不上传、不收集任何数据。

## 关键取舍

- 不做账号体系、不做云同步、不做分享。
- 不做「智能推荐」「自动分类」，用户要的是确定的批量转码。
